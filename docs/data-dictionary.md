# Data Dictionary

## id
Unique record identifier.

## destination_name
Human-readable destination name.

## country_code
Two-letter country code.

## region
Broad geographic region.

## primary_language
Primary language associated with the destination.

## currency_code
Three-letter currency code.

## solo_travel_score
A fictional score from 0 to 100 representing general suitability for solo travelers.

## digital_nomad_score
A fictional score from 0 to 100 representing general suitability for remote work and digital nomadism.
